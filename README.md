# Ausgewählte Probleme aus dem ACM Programming Contest  WiSe 2024/2025

This repository contains solutions to selected problems from the ACM Programming Contest during the **WiSe 2024/2025** semester. The problems are organized into weekly folders (**week_1** to **week_10**) based on the course schedule (Transferred from Kattis).

## Summary

- **Total number of problems attempted:** 47  
- **Total number of overall accepted problems:** 39  
- **Total number of accepted problems without duplicates (as shown in Kattis):** 24  
- **Total number of problems with "Time Limit Exceeded" (TLE):** 3  
- **Total number of problems with "Wrong Answer" (WA):** 5  
- **Overall Kattis Score:** **62.8**
